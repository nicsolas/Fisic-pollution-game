# EQUILIBRIO — Demo Giocabile (v0.2.0 - Atti I-III)

Questa cartella contiene una copia congelata e sempre giocabile della **Demo v0.2.0** (Prologo + Atti I-III), oltre al branch Git `demo-v0.2` e al tag `v0.2.0`.

## Come avviare la Demo
- Da questa cartella:
  ```bash
  ./equilibrio_demo_v0.2
  ```
- Oppure dall'eseguibile principale in modalita' Demo:
  ```bash
  ../build/eco_proto --demo
  ```
  (oppure scegliendo **"Modalita' Campagna: < Demo (Atti I-III) >"** dalla schermata del titolo o dal menu di pausa).
